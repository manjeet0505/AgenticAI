Check if Git is Installed
git --version

 What it does:
Shows the installed Git version on your system.

Example output:

git version 2.44.0

Configure Git (First Time Setup)
2️ Set Your Git Username
git config --global user.name "Your Name"

 What it does:
Sets your global Git username which appears in commits.

Example:

git config --global user.name "Manjeet Mishra"

Set Your Git Email
git config --global user.email "your@email.com"

 What it does:
Associates your email with commits.

Example:

git config --global user.email "manjeet@gmail.com"

Initialize a Git Repository
 Start Git Tracking
git init

 What it does:
Creates a new Git repository in your project folder.

It creates a hidden folder:

.git

This folder stores all Git history.
Check Project Status
5️ Check File Status
git status

 What it does:
Shows:

modified files

staged files

untracked files

Example output:

Untracked files:
  index.js


Add Files to Staging Area
 Add All Files
git add .

 What it does:
Adds all project files to the staging area.

 Add Specific File
git add filename

Example:

git add app.js

 What it does:
Adds only one file to staging.

Save Changes (Commit)
 Commit Changes
git commit -m "initial commit"

 What it does:
Saves a snapshot of your project.

Example:

initial commit
added login feature
fixed bug

Connect Project to GitHub
9️ Add Remote Repository
git remote add origin https://github.com/username/repo.git

 What it does:
Connects your local project to GitHub repository.

Example:

git remote add origin https://github.com/manjeet/portfolio.git

Push Code to GitHub
 Push Code
git push -u origin main

 What it does:

uploads your code to GitHub

origin → remote repo

main → branch name

-u → links local branch with remote branch

After this, next pushes only need:

git push

Pull Latest Code
 Pull Updates
git pull origin main

 What it does:
Downloads latest code from GitHub repository.

Used when:

working in team

repo updated online
